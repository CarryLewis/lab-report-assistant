# 图表自动发现：第一期实现与验证

日期：2026-10-25。依据：[图表自动发现与科学审核模块开发纲领](VISUAL_RECOGNITION_CHARTER.md)。

## 本期交付

已接入本地逐页扫描、图表候选目录、原页高亮、缩略图、人工补选、名称/类型确认、排除/恢复误识别和重新框选。扫描任务支持暂停、续扫、失败页重试和重新扫描。结果与进度保存在现有报告记录中；关闭页面后停止发送下一页请求，重新打开可继续，不承诺浏览器关闭后仍有后台扫描工作进程。

对象发现使用 pdfplumber（MIT）读取图片、线条、矩形、曲线和表格。图片、矢量聚合与表格候选合并去重；表格同时使用线框和文字对齐信号，后者要求数值单元格证据。有线表边界优先于可能吞入附近正文的文字对齐边界。图注只做邻近候选提示，不当作已确认的全文关联。

自动发现完全在本地执行，不需要模型密钥。每页记录已发现候选、本地未发现、待补扫或失败。图像页无可靠文字时即使发现了嵌入图片，仍标为待补扫；“扫描部分完成”不会伪装成全文已检查。未知图片和矢量对象保留“待分类”，教师可修正类型。

目录中的“审核此图”仅准备高分辨率原页截图，打开既有确认窗口。教师点击“发送并审核图表”才调用外部视觉审核；“保存到图表目录（本地）”不发送截图、正文或 CSV。

## 原页与数据保护

- PDF 以原始可见 CropBox 及旋转后的页面为坐标基准；已覆盖旋转 90 度且带裁切框的回归场景。
- DOCX 的阅读器与自动目录共用一份保存的 PDF 预览，避免两次转换产生坐标偏差。原始 DOCX 和预览 PDF 分别校验哈希。兼容 HTML 视图不能用于自动定位，提示导出 PDF。
- 修改接口使用报告 revision 和事务锁；旧版本请求会被拒绝，避免覆盖其他修改。
- 重新扫描保留当前预览版本下的教师修订；重叠的人工补选不会被同一区域的自动候选重复覆盖。
- 每个已存在对象保留最近 50 次修订前状态、时间及 teacher 来源，同时保留累计修订数。该历史随报告保存；尚未提供独立的逐条修订回滚界面。
- 扫描期间暂时禁用评分与反馈输入，避免逐页刷新丢失未保存输入。已有未保存评阅先走现有草稿保存流程。
- 缩略图渲染串行调用 PDFium，避免并行渲染冲突。限制 200 页、每页 80 个候选、每报告 1,000 个候选及页面对象数量；超限明确失败/部分完成。

## 接口与实现入口

以下接口已实现，均位于 `/api/pilot/reports/{id}` 下：

- `POST /visual-scan`：新建、继续、重新扫描或重试失败页。
- `POST /visual-scan-next`：处理下一页；携带 revision 和 scan_id。
- `POST /visual-scan-cancel`：停止后续页面处理，保留已有结果。
- `GET /visual-inventory`：读取任务、对象和报告 revision。
- `POST /visual-object`：新增或修订本地候选，包含原文件哈希。
- `GET /visual-thumbnail/{objectId}`：按版本校验生成本地 PNG 缩略图。
- `GET /visual-preview`：读取与扫描共用的稳定 PDF 预览。

实现入口：`visual_discovery.py`、`visual-inventory.js`，并接入 `pilot_backend.py`、`original-reader.mjs`、`teacher-live.js` 和 `index.html`。依赖和容器复制清单已同步更新。

## 验证与分期边界

新增 Python 回归覆盖：三页图表样本发现与去重、扫描页覆盖状态、缩略图、持久化读取、暂停续扫、幂等启动、修订保留、失败重试、旧 revision/哈希拒绝、矢量图、空白页、旋转裁切坐标，以及 DOCX 阅读和扫描共用预览。

新增前端回归覆盖逐页请求 revision 传递、暂停、保存本地候选和过期原文件拒绝。原有手动 AI 启动测试依据当前自动分析流程更新为自动结果轮询测试，验证教师未保存输入被保留，以及本地扫描期间不抢占界面。

浏览器核对使用虚构报告；不拿真实学生文件作为自动化外发样本。测试数量、截图和真实视觉调用的结果在本次交付记录中注明，不能据此声称通用检测准确率已达标。

仍待后续阶段实现/评测：扫描页 OCR 和模型版面补扫、视觉自动细分类、可靠图注/正文关联、多面板父子关系、跨页表格、目录对象合并/拆分交互，以及批量科学审核队列。当前基础候选检测和邻近图注提示不替代这些能力。正式标注集、按类型召回率/精确率及发布阈值尚未建立；本期属于可运行的第一期工程原型，不能宣称“全部图表零遗漏”。

第一期原型可供使用和样本验证；按纲领进入后续批量审核前，仍需完成独立基线评测与相应阶段门槛。

技术依据：[pdfplumber 官方仓库与接口说明](https://github.com/jsvine/pdfplumber)。

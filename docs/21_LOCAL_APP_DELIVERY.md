# 本机应用交付纲领

决策日期：2026-10-27。本文是当前交付方式的依据；与旧的学校登录、服务器部署、Turnitin/LMS 集成计划冲突时，以本文为准。

## 产品与使用方式

教师下载应用，在自己的电脑上启动和使用。每位教师独立维护本机课程、作业、评分细则、报告与批改记录。现有本地网页工作台可继续作为界面；最终安装包形式和支持的操作系统另行确定，不默认要求教师手工配置开发环境。

工作流：下载与启动 → 配置 AI 服务 → 创建作业并确认 rubric → 导入 DOCX → 自动分析 → 核对原文证据并编辑反馈 → 保存或确认 → 导出反馈。

教师自行取得报告文件，并按学校既有方式使用导出结果。完成批改不依赖登录 Turnitin、连接 LMS 或访问项目方的中央服务器。

## 数据和联网边界

- 原始报告、标准快照、分析结果、教师笔记、修订和进度默认保存在当前电脑。
- 多位教师分别安装使用，不意味着共享数据库、团队协作或自动跨设备同步。
- 本地界面和服务默认仅允许本机访问；不得因打包而直接开放到局域网或公网。
- 调用外部 AI 或文献检索服务仍需要联网；本地保存不等于完全离线。发送前应明确处理内容与服务配置。
- API 密钥保存在本机后台配置中，不进入网页源码、公开仓库、分发包或默认导出包。每个安装单独配置获准使用的服务，不内置共享秘密密钥。

## 近期交付顺序

1. 稳定单教师闭环：导入、分析、证据定位、编辑、保存重开、确认和导出。
2. 改善安装与启动：准备可下载交付物、运行依赖检查、明确错误提示和首次使用说明；Word 转换组件须检测并说明获取方式。
3. 完成本地数据保障：提供明确的数据目录、备份与恢复办法；升级应用时保留报告、评分和草稿，不将用户数据放入可直接替换的程序文件目录。
4. 小范围教师试用：在约定支持的电脑环境验证完整流程，再修复问题并发布更新。

## 暂缓功能

Turnitin 同步与登录、LMS 接入、学校 SSO、中央多人服务器、跨设备自动同步、团队校准和学生端自动投递均不属于当前交付范围。相关代码和历史设计不代表已支持，也不应作为近期开发前置条件。未来是否恢复这些方向须重新确认需求。

## 交付验收

- 教师可以按说明完成下载、启动与服务配置。
- 保存后关闭应用再打开，报告、笔记、评分、建议审核状态及进度可以恢复。
- 缺少网络、API 密钥或转换组件时提示明确，已有工作不丢失；已保存内容仍可查看和编辑。
- 更新应用和执行备份恢复后，用户资料与凭据边界符合上述要求。
- 无需连接 Turnitin 或 LMS 即可完成本机审核和支持格式的反馈导出。

## 2026-10-27 本机试用交付进展

已生成自带 Python 的 macOS Apple Silicon 试用 DMG／ZIP，增加启动窗口、依赖和 TLS 检查、备用端口、实例复用及安装版独立资料目录。75 项 Python、4 项 JavaScript 测试及 9 类包内安装检查通过。详情见[安装交付与验证](23_MACOS_INSTALLATION_AND_RELEASE.md)。

当前只有临时本机代码签名，Developer ID 签名、Apple 公证、Intel／其他系统版本兼容、真实教师试用和自动升级仍未完成。不得将本机试用包称为公开正式发布版。

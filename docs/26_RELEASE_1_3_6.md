# Labwise 1.3.6 开发进度与源码同步

同步日期：2026-11-04。上一公开源码版本：1.3.4。当前 `VERSION`：1.3.6。

## 本次纳入的进展

- 1.3.5 界面统一：共享字体、字号层级、图标、按钮和表单样式；阅读器使用同一套样式资源。
- 1.3.6 批改布局：紧凑操作栏、目录／原文／评阅三栏、按需展开概览与阅读说明；移除旧最小高度约束，调整嵌套滚动、窄屏和拖动布局。

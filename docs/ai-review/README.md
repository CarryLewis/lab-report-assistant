# Labwise AI 评阅开发档案

这里集中记录评分依据如何进入模型、评阅证据如何校验，以及每轮校准得出了什么结论。内容对应 1.4 Beta 开发源码。请按 Git 分支或提交核对实际运行版本。

- [后端规则与代码入口](rules.md)涵盖评分细则、作业适配、图表证据和候选分数。
- [2026-11-09 校准与评分上下文](log/2026-11-09-rubric-calibration.md)记录对照指标、规则来源与缓存测试。
- [2026-11-10 Word 图表评阅](log/2026-11-10-word-figure-review.md)记录图表定位、部分结果保留和本机重放。

迭代按「记录问题 → 确定适用评分表 → 修改后端规则 → 用虚构或获准的留出材料复测」进行。每条日志记录日期、版本、范围、比较口径、结果和未解决问题。把证据定位率、反馈内容的准确性、评分一致性分开统计。

GitHub 档案只保留汇总指标、归纳的案例和虚构测试。课程原稿、评分表原件、逐人分数、教师批注、模型请求与回复、密钥及本地数据库由授权人员在各自环境中管理。

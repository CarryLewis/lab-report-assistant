# 已批改作业 PDF 导出

2026-10-26：在现有教师确认流程中加入 PDF 预览、单份下载和作业题合并导出。

## 教师操作

单份报告：完成教师确认 →「导出反馈」→「预览并下载评阅 PDF」。
同一作业题：全部有效作业确认后，在工作台点击「合并导出 PDF」。导出顺序为学生姓名/编号、文件名、记录 ID，每份报告均有 PDF 书签。

预览使用本地 PDF.js 阅读器。预览和下载共享同一份生成结果。可以开关原文高亮、教师原文批注、评分细则；设置改变后必须重新生成，避免下载旧设置对应的 PDF。生成失败保留重试入口。关闭窗口会清除浏览器中的预览文件地址。

## 文件内容

1. 评分与总评：作业、学生、总分、各维度得分、教师最终反馈、确认时间。
2. 原文页面：Word 在本机转换为 PDF，保留页面内容、表格和图像。默认加宽纸张以容纳右侧旁批栏，保持原有正文显示比例。高亮采用绿色优点、黄色改进建议、蓝色教师批注；旁批以连线和编号对应原文，显示评语节选，同号完整评语见后附评语页。长评语截取并标记省略号；单页超过 10 条时明确提示其余数量，所有完整内容仍保留。关闭高亮时一并关闭旁批栏，原文页使用 A4。
3. 逐条评语：教师采纳或编辑后的建议，以及勾选导出的原文批注；保留完整评语、原文片段、原文页码和来源段落编号。建议没有引文时引用其关联的原文段落；仍无法准确定位的评语标明需核对位置，不猜测旁批位置。
4. 可选评分细则：使用该报告保存的 rubric 快照及分项得分。

私人评阅笔记、未采纳或待确认的 AI 建议均不进入学生 PDF。原文批注与私人笔记是不同字段；原文批注默认勾选，导出面板对此明确提示。已有 Word 批改包入口继续保留。

## 定位与边界

每次导出先验证原文件 SHA-256，再通过转换后 PDF 的文字坐标定位引文。仅忽略空白、软连字符及标准 Unicode 字形差异。引文重复时用唯一匹配的来源段落上下文缩小范围。无法唯一定位、扫描页没有文字、图表建议没有文字引句时，仍导出完整评语并标注「需核对位置」，不猜测高亮。跨页引句在对应原文页分别标记。

Word 的阅读视图不提供可靠分页，所以不把 Word 批注的临时页码直接当作输出 PDF 页码。历史 PDF 的教师选页批注则限定在已选原文页中匹配。旋转页面先统一坐标；裁切页面按可见范围绘制。

Word 导出必须具备 LibreOffice 分页转换组件；无组件时返回明确错误，不把兼容 HTML 或纯文本当作原文 PDF。复杂对象与缺失字体可能影响 Word 转换后的外观，需要教师在预览核对。导出本身不调用 AI，不上传文件，不改变评分与确认状态。

### 提示缺少 LibreOffice 时

macOS 用户可从 [LibreOffice 官网](https://www.libreoffice.org/download/)下载与本机芯片匹配的版本，将 `LibreOffice.app` 安装到 `/Applications` 或 `~/Applications`。应用每次转换都会重新检测，安装完成后可直接重试 PDF 导出。

自定义安装位置可在启动 Labwise 前设置 `LABWISE_SOFFICE`，指向 `LibreOffice.app/Contents/MacOS/soffice` 可执行文件，而非 `.app` 文件夹。若已设置此变量但位置失效，应修正或取消变量；显式配置优先于自动检测。通过 Finder 启动的应用通常不会继承终端中设置的变量，建议使用上述标准安装位置。

PDF 导出会区分缺少组件、组件无法启动、60 秒转换超时和文档转换失败，并保留相应提示。已安装组件但转换失败时，应检查原文件、字体和复杂对象；普通 Word 阅读仍可使用兼容视图。

## 实现

- `pdf_export.py`：原文件校验、分页转换、引文坐标、文字排版、原页叠加、书签与合并。
- `pdf-export.js` / `pdf-export.css`：带内容设置的导出预览窗口。
- `GET/POST /api/pilot/reports/{id}/export-pdf`：单份 PDF。POST 必须携带当前 `revision`，可附 `options`。
- `GET/POST /api/pilot/assignments/{id}/export-pdf`：合并全部未归档、非样例、已确认作业。存在未确认记录时整体拒绝，不生成不完整包。
- `options`：`highlights`、`annotations`、`rubric`，均为布尔值，默认 true。
- 返回 PDF base64、文件名及份数/页数/评语数/未定位数。单原文上限 200 页，批量最多 200 份、2000 页，输入与输出限额 120 MB。
- 新增运行依赖 `reportlab`；复用 `pypdf`、`pdfplumber` 和已有 Word 转换。Docker 已加入新文件。
- 当前项目已配置本地 `.venv`，`start.command` 优先使用它。其他机器可执行 `python3 -m venv .venv`，再用 `.venv/bin/python -m pip install -r requirements.txt` 安装依赖。

## 验证

新增 7 项 PDF 测试通过：原文与评分、反馈筛选、源文件损坏/缺失、未确认与过期修订、重复引文、可选内容、转换组件缺失、旋转页面、批量与 API 状态保持。真实的本机 Word 转换已用仓库虚构生长曲线作业执行，生成 4 页样稿并逐页渲染检查；现有真实学生成绩未改动。

完整 Python 回归执行了 49 项，其中 41 项通过、8 项失败。失败涉及先前 Word-only/自动分析更新后仍调用旧 PDF 上传及手动图表审核的测试，以及旧批注样例缺少 assignment ID；本次未改变这些流程。文章目录 JavaScript 测试通过；旧原页预览与手动 AI 工作流 JavaScript 测试也仍有既有失败。

另在临时副本移除本次新增的 PDF 路由和入口后复核，原有 42 项 Python 测试仍为同样 8 项错误；两个旧 JavaScript 测试的失败也一致。浏览器已验证单份与作业题导出入口、4 页 PDF.js 预览、关闭教师批注后评语数量变化、设置改变后旧下载失效及下载按钮响应。

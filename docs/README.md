## 使用原则

- 所有设计都应服务于教师辅助批改，而不是自动替代教师评分。
- AI 产生的建议必须能回到作业要求、rubric 和报告原文。
- 先完成一门课程的完整闭环，再扩大支持范围。
- 新功能若改变数据范围、教师责任或学校系统接入方式，先在相应文档中补充设计并确认。
